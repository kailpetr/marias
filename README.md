# Mariáš

Webová verze českého mariáše pro jeden prohlížeč. Projekt je postavený jako čistý front-end a jde spustit bez build kroku.

## Spuštění

Otevři `index.html` přímo v prohlížeči, nebo použij libovolný statický server.

## Co hra umí

- 2, 3 nebo 4 hráče
- jeden člověk proti AI
- přiznání barvy
- trumfy
- bodování
- hlášky 20/40
- výukový režim s nápovědou

## Stav projektu

Základní hratelná verze je hotová. Další kroky mohou přidat licitaci, přesnější pravidla pro různé varianty, pokročilejší AI a vizuální sadu autentických mariášových karet.
