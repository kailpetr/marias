# Mariáš

Webová verze českého mariáše pro jeden prohlížeč. Projekt je postavený jako čistý front-end a jde spustit bez build kroku.

## Spuštění

Otevři `index.html` přímo v prohlížeči, nebo použij libovolný statický server.

## Co hra umí

- 2, 3 nebo 4 hráče
- jeden člověk proti AI
- přiznání barvy
- trumfy
- bodování
- hlášky 20/40
- výukový režim s nápovědou
- základní zobrazení mariášových karet

## Stav projektu

Základní hratelná verze je hotová. Další kroky mohou přidat licitaci, přesnější pravidla pro různé varianty, pokročilejší AI, animace a autentičtější vzhled karet.

## Roadmap

1. Licitace a volba hry
2. Hlášky s přesným načasováním
3. Lepší AI se sledováním odhraných karet
4. Klasická sada českých mariášových karet
5. Ukládání rozehrané partie
6. Statistika a historie her
